# Rudolf Art J. Nider — Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript. No frameworks, no build step.

## Run locally
Open `index.html` in a browser.

## Put it online with a www address (free)
1. Create a GitHub repository (for example `portfolio`) and upload `index.html`, `LICENSE.txt` and `README.md`.
2. Go to **Settings > Pages**, set the source to the `main` branch, and save.
3. Buy a domain (for example `rudolfnider.com`) from a registrar.
4. In **Settings > Pages > Custom domain**, enter `www.rudolfnider.com`.
5. At your registrar, add a DNS record: `CNAME`, host `www`, value `<your-github-username>.github.io`.
6. Wait for DNS to update, then tick **Enforce HTTPS**.
